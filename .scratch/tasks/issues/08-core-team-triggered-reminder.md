# 08: Core-team-triggered reminder

**What to build:** a core-team member sends a reminder about one task to its helper, for example when the task has gone quiet. The helper receives it as a push notification and tapping it opens that task. Reminders are always sent manually; nothing is sent automatically and there are no notification settings.

**Blocked by:** 07

**Status:** ready-for-agent

- [ ] A core-team member can trigger a reminder for a task from the task view
- [ ] Every helper assigned to the task receives a push notification
- [ ] Tapping the notification opens that task in the helper app
- [ ] Nothing triggers reminders automatically, and helpers have no notification settings
- [ ] Tests cover triggering a reminder and who receives it
