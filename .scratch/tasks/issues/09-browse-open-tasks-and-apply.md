# 09: Browse open tasks and apply (planned extension)

**What to build:** helpers can browse tasks that still need people and apply for them. This needs a "helpers needed" number per task; a task is full once it has as many helpers as it needs. "My tasks" stays the default view. Open tasks show only their own details, never who is on them. See "Later — planned extensions" in `docs/design/tasks.md`.
