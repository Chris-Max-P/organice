# 04: Helper-owned description

**What to build:** once a task is assigned, the helper can rewrite its description as the task's real shape becomes clear. The core team can read the description but can't edit it. The brief (update 1) stays unchanged, so what was originally asked stays readable.

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] An assigned helper can edit the task's description
- [ ] A core-team member can't edit the description of a handed-off task
- [ ] Editing the description never changes the brief
- [ ] The core-team task view shows the current description
- [ ] Tests cover helper edit, refused core-team edit and that the brief is unaffected
